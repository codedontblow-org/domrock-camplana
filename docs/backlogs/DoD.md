# Definition of Done (DoD)

Uma tarefa é considerada **Done** quando atende aos critérios de qualidade definidos pelo projeto.

## Checklist

- [ ] A implementação foi concluída.
- [ ] O código foi revisado.
- [ ] Não existem erros conhecidos bloqueantes.
- [ ] A documentação necessária foi atualizada.
- [ ] O código segue os padrões definidos pelo projeto.
- [ ] A funcionalidade foi validada conforme os critérios de aceite.
- [ ] O Pull Request foi aprovado.
- [ ] As alterações foram integradas à branch correspondente.
